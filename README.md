Este projeto teve como objetivo aprender a utilizar o python integrado com o sql.

Ferramentas utilizadas:

Python, MySql Workbench, Prompt de Comando

Tópicos abordados:

- Criação e conexão com banco de dados MySql via Python
- Criação, manipulação, remoção e preenchimento de tabelas via Python
- Boas práticas na identação e escrita de consultas, para otimizar a leitura
- Execução de comandos Sql diretamente no prompt de comando do computador como forma de visualizar o que está acontecendo
